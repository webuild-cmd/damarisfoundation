# Damaris Foundation for Premature Infants — Website

## GitHub Pages upload order
Upload these items to the **root of your repository**:

1. `index.html`
2. `style.css`
3. `script.js`
4. `assets/` (upload the whole folder and all files inside it)

`README.md` is optional for the live site.

## Assets
The supplied Foundation/team photographs have been prepared as optimized `.webp` web assets and are already referenced by the code. No manual conversion is required.

## GitHub Pages
Repository → **Settings → Pages** → **Deploy from a branch** → choose `main` and `/ (root)` → Save.

The site is responsive for desktop, tablet and mobile screens. The only intentionally anticipatory section is **Donations — Coming Soon**.
